# Security Policy

This repository intentionally contains no credentials, tokens, customer data, production configuration, private URLs, or internal workflow exports.

## Reporting

Please do not publish a suspected secret or sensitive private data in a public issue. Contact the repository owner privately through the contact method shown on the GitHub profile, with the affected path and a minimal description.

## Scope

Skills are instruction and review packages. They do not authorize access to systems, execution of destructive actions, credential validation, or publication outside the authority explicitly granted by the user.
