# Collection Architecture

The collection is deliberately split by responsibility.

```text
Permanent core
  └─ baseline decision, planning, source, and evidence discipline
On-demand core
  └─ code, security, adversarial, and intake review
On-demand Iron Science domain
  └─ bounded trend, media, edit, QA, and learning reasoning
```

Every skill is explicit about its activation boundary. Review and planning skills do not independently authorize execution, publishing, system access, or external data transfer.

The public package deliberately excludes Iron Science workflows, project architecture, credentials, and production material.
